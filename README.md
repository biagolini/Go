### GitHub Actions Multi-Architecture Image to Amazon ECR

A small Go HTTP server packaged as a multi-architecture container image (`amd64` and `arm64`). A GitHub Actions workflow builds each architecture natively on GitHub-hosted x86 and ARM runners, pushes both images to Amazon ECR with OIDC authentication (no stored AWS keys), joins them into one tag with `docker manifest`, and verifies that each architecture runs. The same tag runs on AWS Fargate on both X86_64 and ARM64.
